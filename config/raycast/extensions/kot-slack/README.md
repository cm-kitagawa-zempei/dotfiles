# KoT Slack

KING OF TIME の打刻に合わせて、勤務場所ごとのメッセージを Slack に投稿する Raycast 拡張です。Chrome 拡張「MyレコーダーChromeアシスタント」の Slack 連携を、ブラウザ拡張なしで使えるようにしたものです。

## できること

- Raycast の「打刻」コマンドで、出勤・休憩開始・再開・退勤のメッセージを選んで Slack に投稿する
- 出勤と再開は、勤務場所ごとのメッセージから選べる
- 打刻に合わせて Slack のステータスを変更する
- 投稿後に Myレコーダーをブラウザで開く

KING OF TIME への打刻そのものは行いません。開いた Myレコーダーで打刻ボタンを押してください。

## インストール

```sh
pnpm install
pnpm run dev
```

Raycast に「打刻」コマンドが登録されたら `Ctrl + C` で止めて構いません。

## 設定

トークンなどは Raycast の設定 (Extensions → KoT Slack) で入力します。

| 項目 | 内容 |
| --- | --- |
| Slack トークン | ユーザートークン（`xoxp-...`）。`chat:write` スコープが必要 |
| 投稿先チャンネル | チャンネル名またはチャンネル ID。複数はスペース区切り |
| Slack ステータス | 有効にすると打刻に合わせてステータスを変える。`users.profile:write` スコープが必要 |
| Myレコーダーの URL | 普段使っている URL（`s2` / `s3` / `s4`、`recorder` / `recorder2`） |

メッセージとステータスの内容は「打刻メッセージの設定」コマンドのフォームで入力します（「打刻」コマンドからも `Cmd + E` で開けます）。メッセージは1行に1つ書き、勤務場所ごとに行を分けます。

入力した内容は `~/.config/kot-slack/config.json` に保存されます。このファイルを直接編集しても構いません。

```json
{
  "messages": {
    "clockIn": ["リモートワーク開始します。", "大阪オフィス出社しました。"],
    "takeABreak": [],
    "breakIsOver": [],
    "clockOut": ["退勤します。"]
  },
  "status": {
    "working": { "emoji": ":office:", "text": "仕事中" },
    "break": { "emoji": ":coffee:", "text": "休憩中" },
    "off": { "emoji": "", "text": "" }
  }
}
```

- `messages` は打刻の種類ごとのメッセージの一覧です。空の配列にした種類は投稿しません
- `status` の `working` は出勤・再開、`break` は休憩開始、`off` は退勤のときに設定します。項目ごと消すとそのときはステータスを変えません。絵文字とテキストを両方空にするとステータスを消します

## Chrome 拡張と併用する場合

ストア版の「MyレコーダーChromeアシスタント」も Slack に投稿するため、同じ打刻で二重に投稿されないよう、どちらか一方だけに設定します。勤務場所で内容を変えたいメッセージはこの拡張に書き、Chrome 拡張側の同じ欄は空にしてください。Incoming Webhook には対応していません。
